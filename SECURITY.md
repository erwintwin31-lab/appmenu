# Sicherheitsrichtlinie

Melde Sicherheitslücken bitte **nicht öffentlich** als Issue. Nutze GitHub Security Advisories oder kontaktiere den Repository-Owner direkt. Füge möglichst Reproduktionsschritte, betroffene Version und Logs hinzu. Sicherheitsfixes erhalten Vorrang und werden nach Bestätigung veröffentlicht.
