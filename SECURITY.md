# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues, pull requests or comments.

Use the repository's Security tab and select "Report a vulnerability" if private vulnerability reporting is available. Otherwise, use a private contact channel provided by the repository owner on their GitHub profile. If no private channel is listed, request one without sharing vulnerability details publicly.

Include, where possible:

- The affected Appmenu version or commit and your operating system.
- A description of the issue, its potential impact and any prerequisites.
- Clear reproduction steps or a minimal proof of concept.
- Relevant logs or screenshots with passwords, tokens and personal information removed.

Only test on systems you own or have explicit permission to assess. Do not include real credentials or other people's data in a report.

## Handling and disclosure

Confirmed security issues take priority. The maintainer will assess reports and coordinate fixes and disclosure with the reporter. Please allow time for investigation and remediation before publishing technical details.

Appmenu is in early development. No fixed response time, remediation deadline or long-term support window is guaranteed.

## Non-security issues

For ordinary bugs, installation problems and feature requests that do not expose a vulnerability, use the repository's issue tracker.
